1. 配置 SQL Server

填写本地 SQL Server 的连接信息和数据表名，然后点击测试。

2. 配置飞书应用

填写自建应用的 App ID / Secret 和目标多维表格 Table ID，然后点击测试。

3. 字段映射

先读取两边的字段，再把「SQL Server 列」对应到「飞书字段名」，并选择一个字段作为「唯一键」（用于去重，建议用订单号/编号类字段）。 完全通用的映射方式，换成任意表和字段都能用。

SQL Server 列 → 飞书字段名
建议选「订单号」「编号」等唯一值字段

4. 执行同步

确认配置无误后，点击下方按钮开始同步。进度和日志会实时显示。
