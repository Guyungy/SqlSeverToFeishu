# SQL Server → 飞书多维表格同步中心

> 不写 SQL、不手改配置文件，在网页中勾选数据库表和字段，即可同步到飞书多维表格。

<p align="center">
  <strong>多数据库 · 自动建表 · 增量同步 · 可视化配置 · 同步前预检</strong>
</p>

---

## ✨ 它能做什么

| 能力 | 说明 |
| --- | --- |
| 多数据源 | 同时连接多个 SQL Server 服务器或数据库 |
| 自动识别 | 自动读取可访问的数据库、表、视图和字段 |
| 勾选配置 | 在网页里选择表和字段，无需手写 SQL |
| 自动建表 | 飞书中没有目标表或字段时可自动创建 |
| 增量同步 | 第一次全量同步，以后只读取新增或修改的数据 |
| 安全预检 | 正式写入前先查看新增、更新、跳过数量 |
| 幂等更新 | 按唯一键新增或更新，未变化的数据自动跳过 |

## 🚀 小白快速开始

### 第 1 步：准备资料

开始前只需要准备以下内容：

- 一台安装了 **Python 3.10 或更高版本**的 Windows、macOS 或 Linux 电脑；
- SQL Server 的服务器地址、端口、数据库名、用户名和密码；
- 飞书自建应用的 **App ID** 和 **App Secret**；
- 一个飞书多维表格的完整网页链接。

> [!TIP]
> SQL Server 建议使用只有 `SELECT` 权限的专用只读账号，不要使用 `sa`。

### 第 2 步：双击“一键启动”

#### Windows

双击 **`一键启动.bat`**。

- 第一次运行：自动安装所需环境并启动；
- 以后运行：直接启动，不会重复安装；
- 启动成功：自动打开管理页面。

#### macOS

双击 **`一键启动.command`**。

- 第一次运行：自动安装所需环境并启动；
- 以后运行：直接启动，不会重复安装；
- 启动成功：自动打开管理页面。

如果系统阻止打开，请右键文件并选择“打开”。

#### Linux

```bash
AUTO_START=1 ./install.sh
```

安装完成后，日常使用运行 `./start.sh` 即可。

> [!IMPORTANT]
> 启动后的命令窗口不能关闭；关闭窗口会同时停止本地同步服务。浏览器没有自动打开时，请访问 <http://127.0.0.1:5001>。

### 第 3 步：在网页完成 4 项配置

```text
飞书空间 → 添加数据源 → 创建同步任务 → 预检并同步
```

1. **飞书空间**：填写 App ID、App Secret 和多维表格完整链接，点击“保存并测试”。
2. **数据源**：填写 SQL Server 连接信息，点击“测试连接”。
3. **同步设计器**：读取数据表，勾选需要同步的表和字段，选择唯一键并保存。
4. **执行与日志**：先点“预检全部任务”，数量正确后再点“同步全部任务”。

就这么多。凭据和任务配置都会由页面自动保存，**不需要创建或编辑 `.env`**。

> [!NOTE]
> 不知道数据库名时，可以先留空保存，再点击“识别可访问数据库”进行选择。

## 🧭 配置时怎么选

### 唯一键

唯一键用来判断一行数据应该新增还是更新。请选择不会重复、不会为空的字段，例如订单号、明细 ID 或业务编号。

如果 SQL 源端唯一键为空或重复，或者飞书目标表中已有重复键，任务会安全停止。

### 增量字段

推荐使用：

1. `UpdatedAt`、`ModifiedTime` 等最后修改时间；
2. 持续递增的流水号或 ID。

首次运行会扫描全表。成功后，程序将游标保存在 `sync_state.json`，下一次从上次成功位置继续读取。边界数据会再次比较，以避免多行使用同一时间戳时漏数据。

只有整张表成功后才会推进游标。任务失败、取消或配置变化时，不会错误跳过数据。需要重新扫描全表时，点击任务上的“重置游标”。

### 飞书目标表

推荐选择“自动匹配或新建表”：

- 已有同名表：直接使用；
- 没有同名表：正式同步时自动创建；
- 已有表缺少字段：开启“自动补建飞书字段”后自动补齐；
- 只做预检：只显示计划，不会创建表或字段。

也可以明确绑定已有飞书表。人员、附件、公式、关联记录等复杂字段需要特殊数据结构，当前不会把普通 SQL 值自动转换成这些类型。

## 🔐 飞书权限准备

飞书自建应用需要拥有以下能力：

- 读取记录；
- 创建和更新记录；
- 创建数据表；
- 创建字段。

开通权限并发布应用版本后，还要把应用添加到目标多维表格，并授予可管理权限。

> [!WARNING]
> 第一次正式同步前，建议先复制一份目标飞书表作为备份。

## ⚙️ 运行设置

这些选项都可以在网页的“运行设置”中修改：

| 设置 | 默认值 | 说明 |
| --- | ---: | --- |
| SQL 查询超时 | 60 秒 | 单条查询最长时间，可设为 1–600 秒 |
| SQL NULL 处理 | 跳过 | `skip` 不覆盖飞书原值；`overwrite` 清空对应字段 |
| 时区偏移 | UTC+8 | SQL 无时区日期的解释方式 |
| 服务端口 | 5001 | 修改后需要重启程序 |

取值优先级通常为“网页设置 > `.env` > 默认值”。服务端口例外：启动命令显式设置 `DASHBOARD_PORT` 时，以命令行为准。

修改时区或 NULL 策略会改变数据含义，因此所有增量任务会在下次运行时自动全量重扫。修改查询超时不会重置游标。

## 🔄 同步规则

### SQL 与飞书类型映射

| SQL Server 类型 | 自动创建的飞书类型 |
| --- | --- |
| 整数、小数、金额、浮点 | 数字 |
| `date`、`datetime`、`datetime2`、`datetimeoffset`、`smalldatetime`、`time` | 日期 |
| `bit` | 复选框 |
| 其他常见类型 | 文本 |

### 增量安全机制

- 查询使用 `增量字段 >= 上次游标`，重复读取边界数据以防漏数；
- 只有新增和更新全部成功后才推进游标；
- 数据源、字段、唯一键、增量字段或目标表变化后，旧游标自动失效；
- 增量字段的 SQL 类型变化后，自动回退为全量扫描；
- SQL 中删除的记录不会自动从飞书删除，避免误删。

## 🩺 常见问题

<details>
<summary><strong>提示“未检测到 Python”或版本不足</strong></summary>

安装 Python 3.10 或更高版本。Windows 安装时请勾选 `Add Python to PATH`，然后重新运行安装脚本。

</details>

<details>
<summary><strong>SQL Server 连接失败</strong></summary>

检查服务器地址、端口、数据库名、账号权限、TCP/IP 和防火墙。命名实例可能使用非 1433 端口，请让数据库管理员确认实际端口。

</details>

<details>
<summary><strong>识别不到数据库</strong></summary>

账号可能没有查看其他数据库的权限。可以直接填写已知数据库名，或者让管理员授权读取目标数据库。

</details>

<details>
<summary><strong>飞书能连接，但不能建表或字段</strong></summary>

检查应用是否拥有数据表和字段管理权限、应用版本是否已发布，以及应用是否已被添加到目标多维表格并获得可管理权限。

</details>

<details>
<summary><strong>预检提示唯一键重复或为空</strong></summary>

请先在 SQL Server 或飞书中处理异常数据。不要绕过检查，否则程序无法确定应该更新哪条记录。

</details>

<details>
<summary><strong>每次都想检查全表</strong></summary>

关闭任务的“启用增量同步”。程序每次会读取全表，但仍只写入新增或变化的数据。

</details>

更多截图式说明和概念解释，请阅读 [《小白使用手册》](./使用手册（小白版）.md)。

## 📁 配置与数据文件

| 文件 | 用途 | 是否包含敏感信息 |
| --- | --- | --- |
| `.env` | 飞书密钥和 SQL 数据源密码，由网页自动维护 | **是，请勿分享或提交** |
| `sync_config.json` | 数据源、字段、任务和运行设置，不含密码 | 否 |
| `sync_state.json` | 每个任务最后成功的增量游标 | 否 |
| `sync.log` | 同步运行日志，自动轮转 | 可能包含业务字段名 |
| `dashboard_server.log` | 管理页面错误日志 | 可能包含错误上下文 |
| `mapping.json` | 旧版单表配置，仅用于迁移兼容 | 视旧配置而定 |

旧版 `.env` 和 `mapping.json` 会在首次加载时尽量迁移，不会删除原文件。

## 🧑‍💻 命令行用法

小白用户可以跳过本节。

```bash
# 预检全部启用任务
.venv/bin/python multi_sync.py --dry-run

# 同步全部启用任务
.venv/bin/python multi_sync.py

# 只预检一个任务
.venv/bin/python multi_sync.py --dry-run --job-id job_xxx
```

## 🛡️ 安全设计

- SQL 标识符经过格式校验和元数据白名单确认；
- 飞书分页、查重或接口失败时立即停止；
- 飞书请求包含超时、有限指数退避和 Token 刷新；
- 批量创建使用幂等标识，降低网络重试导致重复记录的风险；
- 同一时刻只允许一个同步进程；
- 管理页面仅监听 `127.0.0.1`，并包含 Host、Origin 和 CSRF 检查；
- 密钥只保存在本机 `.env`，页面不会回显。
